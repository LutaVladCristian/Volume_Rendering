## Building with CLion

1. Open CLion and select **Open** from the welcome screen.
2. Choose the root directory of this repository containing `CMakeLists.txt`.
3. CLion will configure the CMake project automatically.
4. Use **Build > Build Project** to compile the `Volume_Rendering` target.
5. Run the executable using the generated run configuration.

To see my implementation, go to:
- Source/Laboratoare/MarchingCubes
- Source/Laboratoare/RayCasting

Enjoy! :3
